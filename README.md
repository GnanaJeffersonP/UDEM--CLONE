# UDEM--CLONE
# 🎓 Udemy Clone – Front Page

A simple **Udemy website front-page clone** created using **HTML and CSS**.
This project was developed as a frontend practice project to understand website structure, styling, layouts, navigation bars, course sections, and responsive design.

## 🚀 Project Overview

This project recreates the basic design and layout of the Udemy homepage using only **HTML and CSS**.

The main purpose of this project is to practice:

* HTML page structure
* CSS styling
* Flexbox layouts
* Navigation bars
* Course cards
* Image positioning
* Buttons and links
* Responsive webpage design

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

No JavaScript or backend technologies are used in this project.

## ✨ Features

* 🏠 Udemy-style homepage
* 🔍 Search bar
* 📚 Course categories
* 🎓 Course cards
* 🖼️ Course images
* 🔥 Recommended/popular courses section
* 📱 Basic responsive layout
* 🎨 Styled navigation bar and sections
* 📌 Footer section
